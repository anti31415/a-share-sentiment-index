# Project rules

## Language

- Conversation with the user, and any output shown to the user (reports,
  summaries, dashboards, notifications), is in Simplified Chinese.
- Everything uploaded to GitHub is in English: file and directory names,
  code, comments, docs, commit messages, PR titles and descriptions. The only
  exception is a Chinese string a third-party API requires verbatim, which
  must carry an English comment saying so.
- Scheduled / automated task prompts are written in English, and instruct the
  task to produce its output (summaries, push notifications) in Simplified
  Chinese.
- Chinese-language working documents stay local in `local-notes/`
  (gitignored).
